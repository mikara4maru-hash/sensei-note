# 先生の予定ノート

中学校の先生が、学校行事・授業・校務の予定と準備を管理する個人用Webアプリです。
スマホ・iPad・パソコンのブラウザで動きます。サーバー・月額課金・有料APIは使いません。

## 使い始める（無料）
このフォルダの中身を、無料の静的サイト置き場に置くだけで使えます。

- **GitHub Pages**：GitHubにリポジトリを作り、このフォルダの中身を入れて「Settings → Pages」で公開。
- **Netlify Drop**（https://app.netlify.com/drop）：フォルダをブラウザにドラッグするだけで公開。
- **パソコンだけで試す**：フォルダ内で `python3 -m http.server 8000` を実行し、http://localhost:8000 を開く。

iPhone・iPadでは、Safariで開いて「共有 → ホーム画面に追加」すると、アプリのように起動でき、データも消えにくくなります。

## データの保存
- 予定・準備・メモ・PDF/写真は **その端末のブラウザ内（IndexedDB）** に保存され、外部には送信しません。
- **端末間の同期はありません。** 別の端末へは「設定 → バックアップを保存」したファイルを、移す先で「復元」してください。
- ブラウザのWebサイトデータを消すと、このアプリのデータも消えます。定期的にバックアップしてください。

## 初版でできること
- 「＋追加」からタイトルだけで仮登録（日付・時刻・場所・分類はあとから）。日付なしは「日付未定」へ。
- 週表示（初期画面）：その週の予定と、その週が期限の準備を曜日ごとに表示。期限を過ぎた未完了の準備は、どの週でも上部に表示。準備をタップすると行事の詳細へ。
- 月表示：行事・授業・締切・準備の期限をカレンダーで確認。
- 行事の日付を変えると、関連する準備の期限を一覧表示し「ずらす／そのまま／やめる」を選択。
- PDF・写真・Google Driveリンクの添付。PDFはページごと、写真は位置ごとにメモ（元の資料は変更しない）。
- 予定全体のメモ、「来年度への申し送り」。
- 前年度の行事を検索して複製：開催日を指定、準備の期限を「何日前か」で再計算して確認・修正、完了は未完了に戻す、資料は選んで引き継ぎ。前年度の申し送りを複製画面と今年度の詳細で表示（前年度の記録は残る）。
- バックアップ（資料本体を含む1ファイル）と復元、保存先・同期なし・使用量の表示。
- 試験版：月間行事予定の文字を貼り付けて、日付・行事名・場所の候補を一括登録（写真は端末の文字認識でコピーして貼り付け）。
